## 🐛 Problemas Encontrados y Resueltos

### **Problema 1: Símbolo con :USD**
**Error**: `Kraken symbol LTC/USD:USD not recognized`

**Causa**: CCXT agregaba `:USD` automáticamente para perpetuos

**Solución**:
- Actualizado `testing_session.py` para remover `:USD` en símbolos de Kraken
- Actualizado `KrakenConnector.denormalize_symbol()` para manejar `:USD`

**Código**:
```python
# testing_session.py
if "KRAKEN" in exchange:
    if symbol.endswith(":USD"):
        symbol = symbol.replace(":USD", "")
```

---

### **Problema 2: float() con None**
**Error**: `float() argument must be a string or a real number, not 'NoneType'`

**Causa**: Campos opcionales en posiciones y trades retornaban `None`

**Solución**:
- Agregado manejo de `None` con `or` operator
- `float(pos.get("contracts") or 0)` en lugar de `float(pos.get("contracts", 0))`

**Código**:
```python
# kraken_connector.py
"size": float(pos.get("contracts") or 0),
"entry_price": float(pos.get("entryPrice") or 0),
"unrealized_pnl": float(pos.get("unrealizedPnl") or 0),
```
