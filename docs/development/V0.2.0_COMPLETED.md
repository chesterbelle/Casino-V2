## 🐛 Troubleshooting

### **Problema: Pocas estrategias aprobadas**

**Solución:**
```bash
# Descargar más datos
# Editar scripts/download_training_data.sh
LIMIT=50000  # Más velas

# Re-ejecutar training
./scripts/train_memory.sh
```

### **Problema: Winrate bajo**

**Causas posibles:**
1. Market conditions (bear market)
2. Parámetros de sensores muy agresivos
3. Overfitting

**Solución:**
```python
# Ajustar thresholds de sensores
SENSOR_PARAMS = {
    "StochasticReversion": {
        "low_threshold": 25.0,  # Menos agresivo
    }
}
```

### **Problema: Entrenamiento muy lento**

**Solución:**
```bash
# Entrenar con menos símbolos primero
./scripts/train_memory.sh "BTCUSDT*.csv"

# Luego agregar más
./scripts/train_memory.sh "ETH*.csv"
```
