# 🔧 Pre-commit Setup Guide

## ¿Qué hace pre-commit?

Ejecuta automáticamente herramientas de calidad de código **antes de cada commit**:
- ✅ Formateo automático (black, isort)
- ✅ Linting (flake8)
- ✅ Validaciones básicas (trailing whitespace, archivos grandes, etc.)
- 🔧 Type checking (mypy) - **manual**
- 🧪 Tests (pytest) - **manual**

## Instalación

```bash
# 1. Instalar pre-commit
pip install pre-commit

# 2. Instalar los hooks en el repo
pre-commit install

# 3. (Opcional) Ejecutar en todos los archivos
pre-commit run --all-files
```

## Uso Diario

### Commits normales
```bash
git commit -m "mensaje"
# ✅ Se ejecutan automáticamente: black, flake8, isort, validaciones
```

### Commits rápidos (saltarse hooks)
```bash
git commit --no-verify -m "WIP: trabajo en progreso"
# ⚠️ Útil para commits temporales
```

### Ejecutar tests y mypy manualmente
```bash
# Solo cuando quieras verificación completa
pre-commit run --hook-stage manual --all-files
```

## Configuración Actual

### Hooks automáticos (en cada commit):
- `trailing-whitespace`: Elimina espacios al final de líneas
- `end-of-file-fixer`: Asegura newline al final de archivos
- `check-yaml`: Valida sintaxis YAML
- `check-added-large-files`: Previene archivos >500KB
- `check-merge-conflict`: Detecta marcadores de conflicto
- `debug-statements`: Detecta `print()` y `pdb` olvidados
- `check-ast`: Verifica sintaxis Python
- `black`: Formateo de código
- `flake8`: Linting
- `isort`: Ordena imports

### Hooks manuales (solo cuando lo pidas):
- `mypy`: Type checking estático
- `pytest`: Ejecuta tests

## Desinstalar

```bash
pre-commit uninstall
```

## Recomendación

**Mantén pre-commit activo** para:
- Código más limpio y consistente
- Menos errores en commits
- Mejor colaboración en equipo

Usa `--no-verify` solo cuando realmente necesites commits rápidos.
